# 持ちネタ×リスナー相性マップ 台本集

> [!info] 前提
> 前回ノート [[2026-09-12_音声配信リスナー層リサーチ]] で分かった「リスナーの4層の悩み」（A 入口の不安／B 使ってるけど楽にならない／C 任せるのが怖い／D 続かない）に、tamehiroの持ちネタ7つをぶつけて相性を判定した。
> 判定基準は3つ。**①部族（非エンジニア・30〜50代・小さく稼ぐ人）の悩みと重なるか ②「作業はAIへ、判断は自分に」の旗に載るか ③法的に安全に語れるか。**

> [!warning] 根拠の扱い
> - 数値は公開調査・記事の引用（取得日 2026-09-13、検索結果の要約経由。一次PDF本文は未取得）。台本で読む前に §6 のURLで再確認。
> - **「自分の実数」（返済額・発電量・費用・壊れた回数）は未収集。** §5 に埋めるべき欄を用意した。ここが埋まると全テーマが一次資料になる。
> - 健康と投資は法規制の線が細い。§4 を読まずに収録しない。

## §1 テーマ別詳細

### 1. お金・副業

**根拠（数値）**
- 40代の悩み1位は「お金」（教育費・住宅ローン・老後資金）。40代の80.7%が「現在悩みがある」（NEXER）。
- 正社員の副業実施率は過去最高の11.0%（パーソル第4回）。別調査で副業経験者39.2%、未経験者の7割超が関心。企業の副業容認率64.3%。
- 副業がバレる最大要因は住民税。年20万円超で確定申告。
- AI副業を名乗る高額勧誘が2024〜2026年に急増。30〜100万円超の情報商材。国民生活センターに副業相談が増加。

**リスナーの悩み語彙**
「時間がない」「何から始めれば」「会社にバレる？」「AI副業って怪しくない？」「月1〜3万でいいから」「本業が忙しくて副業どころじゃない」

**仕組み化との接続**
- 順番論：**本業の作業をAIに渡す → 浮いた時間で副業**（記事群の共通推奨）。tamehiroの実物（SNS文章工場・朝の点検）はこの順番の証拠。
- 「1素材3用途」：ミニ講座→ブログ→音声、を実際にやっている＝話せる。
- AI副業詐欺との差別化：**実物で見せる主義・金額を言わない・まず無料で成功体験**、という現在の方針がそのまま反論になる。

**台本案**
1. 「副業の時間がない」人へ。先に本業から1時間を取り返す順番
   - ポイント：時間は捻出するものではなく"回収"するもの／最初に消す作業は「毎週やってる定型」／浮いた1時間で何をするかは決めておく
2. AI副業の勧誘、ぼくが「怪しい」と判断する5つのサイン
   - ポイント：稼げる額を先に言う／実物がない／前払い／急がせる／「誰でも」。逆にこのサイトが何を見せているか
3. 月1万円の副業より、月10時間の自動化の方が人生を変える理由
   - ポイント：1万円は消える、10時間は毎月戻ってくる／時給換算の罠／判断に使う時間が増える

**NGライン**
- 「月○万円稼げます」は言わない（景表法・実績捏造の芽）。サイト脚注「成果を保証しない」と同じ姿勢を音声でも一言入れる。

### 2. 借金

**根拠（数値）**
- 20〜69歳3,000人調査で「4人に1人は借金経験あり」（アシロ）。
- 借金がある世帯：30代24.6%（平均残高1,852万円、住宅ローン含む）、40代26%（1,575万円）。
- 30〜40代が債務整理のボリュームゾーン。「返済能力を高く見積もる」「出費がかさむ」が原因。
- Voicy「借金返済ラジオ」（しゅうへい）：瀬戸内の島から6,000万円の返済過程を毎日配信し人気。回タイトル例「更新するたびにVoicyリスナーが減っている件」「YouTubeやるよりバイトやったほうがコスパよくない？」＝**弱さと実数を出す回が聴かれる**。

**リスナーの悩み語彙**
「誰にも言えない」「リボの残高を見るのが怖い」「返せるのか分からない」「副業で返そうとして情報商材に…」「毎月の返済で貯金も投資もできない」

**仕組み化との接続**
- 「見るのが怖い数字」を**毎朝1コマンドで見える化**＝点検係の思想と完全に同型。「自動化は壊れても黙っている」→「借金も黙って増える」。
- 判断ログ：借りた理由・返した順番・失敗を記録する＝OS正典の「決定ログ」。
- 借金がある人ほど「時間もお金もない」＝**無料で始められる自動化**が刺さる。

**台本案**
1. ぼくの借金の話をします（初回・信用の土台回）
   - ポイント：いくら・なぜ・今どうしているか（§5で実数を埋める）／隠さない理由／この番組が金額を言わない理由との整合
2. 借金の残高を「毎朝見る」仕組みにしたら、返済が進んだ
   - ポイント：怖い数字ほど自動で目の前に出す／見た瞬間に判断が変わる／点検係と同じ作り
3. 借金がある人ほど、AIを使うべき3つの理由
   - ポイント：時間がない人の味方／無料枠で始まる／副業より先に支出と作業を減らす
4. 「返済のために副業」で失敗する人の順番
   - ポイント：焦り→高額教材→さらに借金。実物のないものに払わない

**NGライン**
- 債務整理・法的手続きの助言はしない（弁護士・司法書士の領域）。「ぼくはこうした」に留め、制度の一般論は出典を添える。

### 3. 投資（株式・ビットコイン）

**根拠（数値）**
- 日経マネー2026年8月号・個人投資家7,500人調査：**4割強がAIを投資に活用**、人気はChatGPTとGemini。「AI・半導体」への投資意欲が高い。
- 別調査：個人投資家の73.3%が株式投資で生成AIを活用、うち89.2%がAI分析をもとに売買経験。
- ChatGPTの個別株予測精度は51%（フロリダ大学）＝コイン投げ。凄腕投資家は**会社概要・競合・シェアの把握**にAIを使う（ログミー）。
- 30代男性の投資関心36.0%、40代29.0%（ネオマーケティング2026）。
- 新NISA：「結局何を買えばいいのか分からない」「下落を経験して続けて大丈夫か不安」が典型。
- ビットコイン：日本人保有率は推定10〜15%、保有者約500万人。最大の壁は税制（雑所得・最大55%）。2026年6月に申告分離課税の政策提言。
- **法規制**：報酬を受けて個別の投資判断を助言すると投資助言・代理業（無登録は5年以下の懲役等）。**不特定多数向けに、誰でも随時購入可能な方法で提供する分析は該当しない**。有料コミュニティ・DMでの個別助言が危険ライン。

**リスナーの悩み語彙**
「何を買えばいい」「AIに聞いたら当たる？」「下がったとき続けていいか」「情報が多すぎて疲れる」「税金が怖い（BTC）」「毎日チャートを見てしまう」

**仕組み化との接続**
- 既に「投資分析を仕組み化して運用中」（サイト記載）＝**実物がある**。
- 旗との一致：「AIは集める・整える・記録する。買うかどうかは自分が決める」。予測精度51%のデータが、そのまま「判断は自分に」の根拠になる。
- 「毎日チャートを見てしまう」→「見る時間を決めて、あとは自動レポート」＝点検係の応用。

**台本案**
1. AIに「この株上がる？」と聞くのをやめた理由（精度51%の話）
   - ポイント：予測ではなく前提整理に使う／凄腕は会社概要と競合を聞いている／判断は自分
2. 投資の情報疲れを、朝の自動レポート1枚にした話
   - ポイント：見る時間を決める／集めるのはAI・決めるのは自分／壊れたときの見え方
3. ビットコインの税金、ぼくが記録を自動化した理由
   - ポイント：雑所得・損益計算の面倒さ／取引履歴→集計の仕組み／制度は変わるので必ず一次情報で確認
4. 新NISAが下がって不安な人へ。「ルールを先に書いておく」という仕組み
   - ポイント：CLAUDE.mdに自分のルールを書くのと同じ／感情ではなく事前ルールで動く

**NGライン（最重要）**
- **銘柄名・売買推奨・「今が買い」は言わない。** 自分の記録と考え方だけ。
- 有料LINE・講座で個別の投資相談に答えない（投資助言業に踏み込む）。
- 「AIで儲かる」は言わない。精度51%の話を先に置く。
- BTC税制・NISA制度は年度で変わる。**放送時に一次情報（国税庁・金融庁）で再確認**（鮮度の掟）。

### 4. テクノロジー：太陽光発電

**根拠（数値）**
- 2026年度からFITが大幅変更。**「売電で儲ける」から「自家消費で節約」へ**。住宅用売電価格は2012年42円→2026年14.6円/kWh。5年目以降は市場連動（8.3円/kWh想定の記述あり）。
- 卒FIT後は蓄電池＋自家消費が経済合理的。蓄電池110〜260万円。「やめたほうがいい？」「後悔」系の記事が上位＝**判断に迷っている層が多い**。
- 電気料金は年平均2〜3%上昇見込み。再エネ賦課金4.18円（2026）。
- 個人実装例：メーカーの発電リモコン／WebモニタリングからデータをGASでスプレッドシートに自動蓄積するパターンが公開されている。AI最適制御（天気予報×過去実績で充放電）が実用化。

**リスナーの悩み語彙**
「太陽光って今からでも元取れる？」「蓄電池は要る？」「発電量をちゃんと見てない」「業者の言うことが正しいか分からない」「卒FITで売電が激減した」

**仕組み化との接続**
- **発電量・売電・買電をログして毎朝レポート**＝点検係のそのまま応用。「太陽光は壊れても黙っている」（パワコン停止に気づかない問題）は、自動化の「黙って壊れる」と同じ構造。
- 「業者の試算を信じる」→「自分の数字で判断する」＝判断は自分に。
- 珍しいテーマなので**番組の記憶フック**になる（「太陽光のデータをAIで見てる人」）。

**台本案**
1. 太陽光パネルの発電量を、毎朝AIに報告させている話
   - ポイント：何を取っているか（発電・売電・買電・天気）／異常をどう検知するか／実数（§5）
2. 2026年のFIT改定で「売電」から「自家消費」に頭を切り替えた話
   - ポイント：単価の推移／蓄電池の元が取れる条件（持ち家・昼余る・補助金）／決めたのは業者の試算ではなく自分のログ
3. 「太陽光は壊れても黙っている」パワコン停止に気づけた／気づけなかった話
   - ポイント：点検係の思想の実例／人間は毎日見ない／見なくても届く仕組み
4. 電気代が上がる時代の"家のデータ"の取り方（初心者向け）
   - ポイント：スマートメーター・メーカーアプリのCSV／スプレッドシートに貯める／AIに「先月と比べて」と聞く

**NGライン**
- 補助金・単価・制度は年度で変わる。放送時に経産省・自治体の一次情報で確認して「2026年9月時点」と付ける。
- 特定業者の推奨・紹介リンクを付ける場合はPR明記（ステマ規制）。

### 6. 田舎

**根拠（数値）**
- 地方・郊外でテレワークする人の**7割超が「生活の質向上」**（マイナビ2026/8）。
- 地方移住の条件1位「フルリモートで働ける仕事」（全年代33〜41%、フルリモート勤務者では55.4%）。40代は「地方でも都心と同等の給与」32.5%（テレリモ総研2026）。
- 生成AI導入：都道府県87.2%、指定都市90%に対し**その他市区町村29.9%、町村は1割前後**（総務省調査の解説）。＝地方はAI活用が遅れており、**一人で仕組み化できる人の希少性が高い**。
- 2026年の移住トレンドは「働ける郊外・育てやすい地方」。クラウドソーシング案件の約8割が在宅完結型。
- 先行例：Voicy「借金返済ラジオ」は"瀬戸内の島から"という場所が番組の顔になっている。

**リスナーの悩み語彙**
「田舎は仕事がない」「周りにAIを使ってる人がいない」「相談相手がいない」「移住したいが収入が不安」「地元の商売にAIなんて…」

**仕組み化との接続**
- 「周りに使う人がいない」＝Leachの「足りないのはツールではなく伴走者」62%と同根。**LINEで質問に答える**運営がそのまま解。
- 「地方こそ一人分の差が出る」：町村のAI導入1割前後というデータが、そのまま励ましになる。
- 田舎暮らしの雑談（季節・生活）は、AI回の「機械っぽさ」を中和する人間味枠。

**台本案**
1. 田舎に住んでいる非エンジニアが、AIで仕事を回している話（自己紹介回）
   - ポイント：場所・生活・なぜAI／周りに使う人がいなくても困らない理由
2. 「周りにAIを使う人がいない」は、田舎ではむしろチャンス
   - ポイント：町村の導入率1割前後／地元の商売の定型作業は都会と同じ／小さく見せて信頼を得る
3. 田舎で"時間"がどう変わったか（通勤ゼロと自動化の合わせ技）
   - ポイント：浮いた時間の使い道／判断に使う時間／生活の質7割向上の実感
4. （雑談）今週の田舎の出来事＋今週壊れた自動化
   - ポイント：2コーナー構成の型。近況→実物の失敗談

**NGライン**
- 自治体名・個人が特定される話は控える。移住の勧めは「ぼくの場合」に留める。

### 7. 健康：レーシック／いびき／ひげ脱毛／サプリ

**根拠（数値）**
- クロス・マーケティング「身体の悩みに関する調査（2026）男性編」：体調で気になること上位は**「目の不調」「睡眠の質低下」「睡眠時間の不足」（全体で4割台）**。40〜60代は「抜け毛・薄毛」「体重や体型」が2割台。
- **レーシック／ICL**：ICL両眼50〜80万円、レーシック20〜40万円。40代以降は老眼との兼ね合いで「おすすめしない」と言われるが、40代で満足した体験談も。医療費控除の対象。
- **いびき／睡眠時無呼吸**：2026年6月からCPAPの保険適用基準が拡大。CPAP月4〜5千円、マウスピースは保険適用で約2万円。40代以降で増加。
- **ひげ脱毛**：30代・40代とも懸念1位は料金、次いで肌トラブル・痛み。動機に「体毛が濃く清潔感」「**毎日のひげ剃りが面倒、替刃代を考えると脱毛の方がトータル安い**」。医療レーザー5〜7回で自己処理が減り、完了は10〜20回。40代で白髪が出ると効きにくい。
- **サプリ**：健康食品・サプリ利用目的1位「食事で不足する栄養素を補う」37.4%、次いで疲労回復・腸内環境（クロス・マーケティング2026）。男性40〜50代は摂取を「以前と変わらず維持」58.9%。40代前半の関心が突出。
- **法規制**：一般消費者が事業者の関与なく自発的に書く感想は健康増進法・医療広告GLの対象外。**ただし**、クリニック・商品の紹介リンクや提供を受けた場合は広告扱い（医療広告GL・薬機法・景表法・ステマ規制）。治療効果の体験談は医療広告では禁止事項。サプリは「効く・治る・痩せる」の効能表現が薬機法NG。

**リスナーの悩み語彙**
「目が疲れる・コンタクトが面倒」「朝スッキリしない・家族にいびきを指摘された」「毎日のひげ剃りが面倒」「サプリ、効いてるのか分からない」「高いけど元は取れる？」「40代でやって後悔しない？」

**仕組み化との接続（ここが肝）**
- 4つとも**「一度の決断・投資で、毎日の作業や不調を消す」**話。＝自動化の思想（フォルダ整理を1回の指示で片付ける）と同じ型。ひげ脱毛の「替刃代を考えたら安い」は、まさに「時給換算で自動化の元を取る」計算と同じ。
- サプリは**「記録して効果を検証する」**＝計測は自動化されたリサーチ。「効いてるか分からない」→睡眠・体重・体調のログをAIに集計させる話にできる。
- いびき＝睡眠の質＝判断の質。「作業はAIへ、判断は自分に」の"自分"のメンテナンス回。
- 健康回は**人間味と信用**の枠。40代男性の悩み上位（目・睡眠・薄毛・体型）と一致しているので、共感の入口として強い。

**台本案**
1. レーシックを受けたときの「決め方」の話（40代・老眼・費用・医療費控除）
   - ポイント：迷った点／何を数字にして決めたか／受けた後の毎日の作業がどれだけ消えたか／**効果の断定はせず「ぼくの場合」**
2. いびき治療で、朝の判断力が変わった話
   - ポイント：家族の指摘→検査→治療の選択肢（CPAP/マウスピース）／月いくら／睡眠は判断の資本／2026年6月の保険適用拡大は一次情報で確認
3. ひげ脱毛は「毎日5分の作業をAIに渡す」のと同じ計算だった
   - ポイント：年間の時間と替刃代／回数と痛み／白髪が出る前に／清潔感の話は控えめに
4. サプリが効いているか分からないので、記録をAIに集計させた
   - ポイント：何を記録したか（睡眠・体重・主観）／「効いた」ではなく「変わった／変わらなかった」を数字で／飲む・やめるは自分で決める
5. 40代男性の体の悩み上位4つ（目・睡眠・薄毛・体型）と、ぼくが打った手
   - ポイント：調査の数字→自分の順番→仕組みで続ける

**NGライン（最重要）**
- **効果・治癒・安全性の断定をしない。**「治った」「誰でも」「絶対」はNG。「ぼくの場合」「医師に相談」を毎回入れる。
- **クリニック名・商品名＋紹介リンク／提供を受けた話は広告扱い**。やるならPR明記＋医療広告GL・薬機法チェック。原則、名前を出さず体験と決め方だけ語る。
- サプリは「疲労回復に効く」「痩せる」等の効能表現をしない。「栄養を補う目的で飲んでいる」まで。
- 医療費控除・保険適用の話は制度が変わるため一次情報を添える。
